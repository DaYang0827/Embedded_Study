# 00 小知识点串联图

#node/入口 #chain/总览

这版是“少量小节点 + 明确应用链”，不是把所有概念都铺开。

## 先看这 5 条链

### 1. 指针到回调

[[05 指针]] -> [[10 函数指针]] -> [[11 回调函数]] -> [[16 USART]] -> [[29 RTOS调度]]

### 2. 指针到 DMA

[[05 指针]] -> [[06 数组]] -> [[18 Buffer]] -> [[17 DMA]] -> [[19 Ring Buffer]]

### 3. volatile 到驱动

[[04 const volatile]] -> [[13 寄存器映射]] -> [[14 位操作]] -> [[15 中断]] -> [[16 USART]]

### 4. 数据流到 Bootloader

[[16 USART]] -> [[17 DMA]] -> [[18 Buffer]] -> [[19 Ring Buffer]] -> [[20 数据帧]] -> [[22 CRC]] -> [[27 IAP]]

### 5. Bootloader 跳转

[[24 向量表]] -> [[25 Reset_Handler]] -> [[26 MSP VTOR]] -> [[10 函数指针]] -> [[28 Bootloader跳转APP]]

## 应用收束

[[27 IAP]]、[[28 Bootloader跳转APP]]、[[29 RTOS调度]] 最后都汇到 [[33 面试应用]]。
